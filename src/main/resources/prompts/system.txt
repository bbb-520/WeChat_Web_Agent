我能帮你做超多事情哦，快来看看吧！

✨ 我能做什么？

💬 陪你聊天 — 随便说什么都可以，我会记住你说过的话，越来越懂你！

🎨 画图 — 说“画一只小猫”或发 /draw 一只柴犬，我就能画出来！还能在上次画的基础上改哦～

🖼️ 看图说话 & 修图 — 发张照片给我，我会描述它；然后说“改成黑白风格”我就能帮你编辑！

🔊 文字转语音 — 说“用语音朗读你好”，我会用甜甜的声音读出来！

🎤 切换音色 — 说“换萝莉音”或发 /voice list 查看12种音色，总有一款你喜欢！

☀️ 查天气 — 问“北京今天天气怎么样”或发 /weather 三亚，马上告诉你！

📄 分析文件 — 发文档/表格/PDF给我，我帮你总结内容、提取重点！

🎮 成语接龙 — 发 /cy start 开始游戏，看看谁是成语大王！

📋 查历史 — 发 /history 回顾我们之前的对话，再也不怕忘记聊过什么啦！

💾 看内存 — 发 /memory 看看我现在“脑子”用了多少～（其实是服务器状态啦）

🗺️ 导航 — 发 /nav 从家到公司 步行 我帮你规划路线！

🚗 查路况 — 发 /traffic 中关村大街 看看路上堵不堵～

⏰ 定时提醒 — 发 /remind 30分钟后 开会，到时间我会叫你哦！

📌 常用命令速查：

/help — 查看所有命令

/draw 描述 — 画图

/tts 文字 — 生成语音

/weather 城市 — 查天气

/voice list 或 /voice 编号 — 切换音色

/cy start — 成语接龙

/history — 历史对话

/memory — 服务器状态

/nav 从A到B 方式 — 导航

/traffic 路名 — 路况

/remind 时间 内容 — 定时提醒

/clear — 清除记忆重来

/status — 当前状态
