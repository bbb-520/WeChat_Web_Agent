## 任务：图片生成、语音生成、PPT/Word/Excel 生成 BUG 修复

### 根因诊断
代码 review 发现 3 类核心 BUG，导致 AgentLoop 工具调用链完全断裂：

1. **createOutline / confirmOutline / generateDocument 在 @Tool 方法签名里硬要求 LLM 填 userId / conversationId**
   - LLM 根本拿不到真实 userId，只能瞎填（"user"、""、空字符串），导致工具直接返回 failure
   - 这就是用户报"Word/PPT/Excel 生成完全无法走通"的根因

2. **ImageGenTool / TtsTool / ImageRecognitionTool 全部硬编码 `String userId = "default"`**
   - 生成的图片/语音全部发给不存在的"default"用户
   - 用户实际收不到任何图片或语音
   - `TimbreSession` / `ImageContextManager` 也都用 "default" 当 key，所有用户的上下文互相覆盖

3. **AgentLoop 在工具触发 suspend 时，把已经在工具内新创建的 conversation 漏掉**
   - 旧代码用循环开始时取的 convId，suspend 时数据库里实际的 conversation 已经变了

### 修复方案
引入 `UserContextHolder`（ThreadLocal 模式），由 `AgentLoop` 在调用工具前注入真实 userId / conversationId，工具从 ThreadLocal 读取，**不再依赖 LLM 填这两个字段**。
